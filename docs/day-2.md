# Day 2 — Computer Hardware

## Learning Objectives

By the end of this lesson, you should be able to:

- Identify major computer components
- Explain the purpose of the CPU
- Describe the difference between RAM and storage

## CPU

The **CPU**, or Central Processing Unit, executes instructions and performs calculations.

## RAM

**RAM** provides temporary working memory for programs that are currently running.

## Storage

Storage retains information even when the computer is turned off.
