## 2. Translating words into algebra

A word problem often describes a mathematical operation without using its symbol. Before solving a problem, translate the statement into an expression or equation.

### Common mathematical phrases

| Words | Mathematical meaning | Example |
|---|---|---|
| A number plus 5 | Add 5 | \(x+5\) |
| A number minus 5 | Subtract 5 | \(x-5\) |
| 5 less than a number | Subtract 5 from the number | \(x-5\) |
| 5 more than a number | Add 5 to the number | \(x+5\) |
| Twice a number | Multiply by 2 | \(2x\) |
| Three times a number | Multiply by 3 | \(3x\) |
| Half a number | Divide by 2 | \(\frac{x}{2}\) |
| The quotient of a number and 4 | Divide the number by 4 | \(\frac{x}{4}\) |
| A number is equal to 12 | Set the number equal to 12 | \(x=12\) |

**Pay attention to word order.** “Five less than a number” is \(x-5\), not \(5-x\). The phrase tells you to start with the number and then subtract five.

### Worked example 1: Translating a phrase

Write “seven more than twice a number” as an algebraic expression.

Step 1: Let \(x\) represent the unknown number.

Step 2: “Twice a number” means multiply the number by 2.

\[
2x
\]

Step 3: “Seven more than” means add 7.

\[
\boxed{2x+7}
\]

This is an expression, not an equation, because the phrase does not tell us that the quantity equals a particular value.

### Worked example 2: Translating a complete statement

Write “three less than twice a number is 11” as an equation.

Step 1: Let \(x\) represent the unknown number.

Step 2: “Twice a number” becomes \(2x\).

Step 3: “Three less than” means subtract 3 from that quantity.

Step 4: “Is 11” means equals 11.

\[
\boxed{2x-3=11}
\]

The word **is** often signals an equals sign in a word problem.

## 3. Solving word problems with equations

A reliable process for solving a word problem is:

1. Read the problem and identify what quantity is unknown.
2. Define a variable to represent the unknown quantity.
3. Translate the important information into an equation.
4. Solve the equation using the methods from Day 4.
5. Check that the answer makes sense in the original situation.
6. State the answer in words, including units when appropriate.

### Worked example 3: A simple number problem

A number increased by 8 equals 23. What is the number?

Step 1: Let \(x\) represent the number.

Step 2: Translate the statement into an equation.

\[
x+8=23
\]

Step 3: Subtract 8 from both sides.

\[
x=15
\]

Step 4: Check: \(15+8=23\), which is true.

Final answer: **The number is 15.**

### Worked example 4: A purchase problem

A notebook costs $4. A student buys several notebooks and spends $28 in total. How many notebooks did the student buy?

Step 1: Let \(n\) represent the number of notebooks.

Step 2: Each notebook costs $4, so the total cost is \(4n\).

Step 3: The total is $28, so write the equation.

\[
4n=28
\]

Step 4: Divide both sides by 4.

\[
n=7
\]

Step 5: Check: seven notebooks at $4 each cost $28.

Final answer: **The student bought 7 notebooks.**

### Worked example 5: A two-step age-style problem

A number is multiplied by 3, then 5 is added. The result is 26. Find the number.

Step 1: Let \(x\) represent the number.

Step 2: Translate the statement.

\[
3x+5=26
\]

Step 3: Subtract 5 from both sides.

\[
3x=21
\]

Step 4: Divide by 3.

\[
\boxed{x=7}
\]

Step 5: Check: \(3(7)+5=21+5=26\).

Final answer: **The number is 7.**

## 4. Working with formulas

A **formula** is an equation that describes a relationship between quantities. Formulas are common in mathematics, science, business, and technology.

For example, the formula for the perimeter of a rectangle is:

\[
P=2l+2w
\]

where:

- \(P\) represents perimeter.
- \(l\) represents length.
- \(w\) represents width.

A formula is an equation, so the equation-solving skills from Day 4 still apply.

### Evaluating a formula

To **evaluate** a formula, substitute the known values for the variables and then calculate.

### Worked example 6: Perimeter of a rectangle

A rectangle has a length of 8 inches and a width of 3 inches. Find its perimeter.

Start with the formula:

\[
P=2l+2w
\]

Substitute \(l=8\) and \(w=3\):

\[
P=2(8)+2(3)
\]

Multiply:

\[
P=16+6
\]

\[
\boxed{P=22\text{ inches}}
\]

### Worked example 7: Distance, rate, and time

A useful relationship is:

\[
d=rt
\]

where:

- \(d\) is distance.
- \(r\) is rate or speed.
- \(t\) is time.

A car travels at 50 miles per hour for 3 hours. How far does it travel?

Substitute the known values:

\[
d=50(3)
\]

\[
\boxed{d=150\text{ miles}}
\]

The units are important: miles per hour multiplied by hours gives miles.

### Rearranging a simple formula

Sometimes a problem gives you a formula but asks you to find a different variable. You can solve the formula just like an equation.

For example, begin with:

\[
d=rt
\]

To solve for \(t\), divide both sides by \(r\), assuming \(r\ne0\):

\[
\frac{d}{r}=\frac{rt}{r}
\]

\[
\boxed{t=\frac{d}{r}}
\]

This process is called **rearranging a formula** or **solving a literal equation**. A literal equation contains more than one variable.

### Worked example 8: Solving a formula for a different variable

Use the formula \(P=2l+2w\) to solve for \(l\).

Step 1: Start with the original formula.

\[
P=2l+2w
\]

Step 2: Subtract \(2w\) from both sides.

\[
P-2w=2l
\]

Step 3: Divide both sides by 2.

\[
\boxed{l=\frac{P-2w}{2}}
\]

You do not need to memorize this rearranged version. Focus on understanding how the equation was changed while keeping both sides balanced.

## 5. The coordinate plane

The **coordinate plane** is a two-dimensional system used to locate points. It has two number lines that cross at right angles:

- The horizontal number line is the **x-axis**.
- The vertical number line is the **y-axis**.
- Their intersection is the **origin**, written as \((0,0)\).

A point is identified by an **ordered pair**:

\[
(x,y)
\]

The first number tells you how far to move horizontally. The second number tells you how far to move vertically.

### The four quadrants

The axes divide the coordinate plane into four regions called quadrants.

| Quadrant | Sign of x | Sign of y |
|---|---|---|
| I | Positive | Positive |
| II | Negative | Positive |
| III | Negative | Negative |
| IV | Positive | Negative |

The quadrants are numbered counterclockwise, beginning in the upper-right region.

### Worked example 9: Locating a point

Which quadrant contains the point \((-3,2)\)?

Step 1: Look at the x-coordinate. It is -3, so move left from the origin.

Step 2: Look at the y-coordinate. It is 2, so move up.

A point that is left of the y-axis and above the x-axis is in Quadrant II.

\[
\boxed{\text{Quadrant II}}
\]

A useful memory aid is to check the signs first:

- \((+,+)\): Quadrant I.
- \((-,+)\): Quadrant II.
- \((-,-)\): Quadrant III.
- \((+,-)\): Quadrant IV.

Points that lie directly on an axis are not in any quadrant.

## 6. Understanding slope

The **slope** of a line describes how steep it is and whether it rises or falls as you move from left to right.

Slope is often described as **rise over run**:

\[
\text{slope}=\frac{\text{vertical change}}{\text{horizontal change}}
\]

The standard slope formula uses two points:

\[
m=\frac{y_2-y_1}{x_2-x_1}
\]

Here, \((x_1,y_1)\) and \((x_2,y_2)\) are the two points, and \(m\) represents slope.

The order matters: subtract the y-coordinates in the same order as the x-coordinates.

### Worked example 10: Finding slope from two points

Find the slope of the line passing through \((1,2)\) and \((3,6)\).

Step 1: Identify the coordinates.

\[
(x_1,y_1)=(1,2),\qquad (x_2,y_2)=(3,6)
\]

Step 2: Substitute into the slope formula.

\[
m=\frac{6-2}{3-1}
\]

Step 3: Simplify.

\[
m=\frac{4}{2}
\]

\[
\boxed{m=2}
\]

The line rises 2 units for every 1 unit it moves to the right.

### Positive, negative, zero, and undefined slopes

| Slope | What the line does | Example |
|---|---|---|
| Positive | Rises from left to right | \(m=2\) |
| Negative | Falls from left to right | \(m=-2\) |
| Zero | Horizontal line | \(m=0\) |
| Undefined | Vertical line | Division by zero in the slope formula |

A horizontal line has no vertical change, so its slope is zero. A vertical line has no horizontal change; because division by zero is undefined, its slope is undefined.

## 7. Slope-intercept form

A common way to write a linear equation is **slope-intercept form**:

\[
y=mx+b
\]

In this equation:

- \(m\) is the slope.
- \(b\) is the y-intercept, the value of y where the line crosses the y-axis.

The y-intercept is the point \((0,b)\). It occurs where \(x=0\).

### Worked example 11: Identifying slope and y-intercept

Consider:

\[
y=-2x+3
\]

Compare it with the standard form:

\[
y=mx+b
\]

The coefficient of \(x\) is -2, so:

\[
m=-2
\]

The constant is 3, so:

\[
b=3
\]

Final answer:

- Slope: \(\boxed{-2}\)
- y-intercept: \(\boxed{3}\), or the point \((0,3)\).

This is the same kind of question you answered correctly in the diagnostic.

### Worked example 12: Finding points from an equation

Use the equation \(y=2x+1\) to find y when \(x=0\) and when \(x=2\).

For \(x=0\):

\[
y=2(0)+1=1
\]

This gives the point \((0,1)\).

For \(x=2\):

\[
y=2(2)+1=5
\]

This gives the point \((2,5)\).

The two points are \((0,1)\) and \((2,5)\). Both satisfy the equation. A straight line can be drawn through them.

## 8. A weekly skills review

This week introduced several connected ideas. Here is a summary of the core rules and procedures.

| Topic | Key idea or rule |
|---|---|
| Signed numbers | Same signs when multiplying or dividing give a positive result; different signs give a negative result. |
| Fractions | Use a common denominator to add or subtract; multiply numerators and denominators to multiply. |
| Simplifying fractions | Divide the numerator and denominator by the same nonzero common factor. |
| Like terms | Combine terms only when their variable parts and exponents match. |
| Distributive property | \(a(b+c)=ab+ac\). |
| Exponents | When multiplying powers with the same base, add exponents. |
| Square roots | \(\sqrt{a}\) is the nonnegative number whose square is \(a\), for \(a\geq0\). |
| Order of operations | Grouping, exponents, multiplication/division left to right, addition/subtraction left to right. |
| Equations | Perform the same operation on both sides to preserve equality. |
| Inequalities | Reverse the symbol when multiplying or dividing both sides by a negative number. |
| Coordinate pairs | The x-coordinate comes first; the y-coordinate comes second. |
| Slope | \(m=\frac{y_2-y_1}{x_2-x_1}\). |

You do not need to memorize this entire table in one sitting. Use it as a reference while practicing. The goal is to recognize which idea applies to a problem and know how to use it.

## 9. Common mistakes to avoid

| Common mistake | Correct approach |
|---|---|
| Translating “5 less than x” as \(5-x\) | “5 less than x” is \(x-5\). |
| Forgetting to define the unknown in a word problem | State what your variable represents before writing the equation. |
| Writing an expression when the problem gives an equality | Translate words such as “is,” “equals,” or “totals” into an equals sign when appropriate. |
| Substituting a value but forgetting parentheses | Replace the variable with the value in parentheses, especially when it is negative. |
| Mixing up the coordinates | Ordered pairs are always written \((x,y)\). |
| Choosing a quadrant based on only one coordinate | Use both signs: the signs of x and y determine the quadrant. |
| Reversing the subtraction order in only part of the slope formula | Subtract y-values in the same order as the x-values. |
| Calling the constant in \(y=mx+b\) the slope | The coefficient of x is the slope; the constant is the y-intercept. |
